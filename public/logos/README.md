# Kit logo A² Events

Toutes les variantes du logo, prêtes à l'emploi.

## SVG (vectoriel — qualité infinie, à privilégier)
- `logo-color.svg` — version couleur officielle (dégradés rouge/sombre)
- `logo-white.svg` — blanc, pour fonds sombres
- `logo-black.svg` — noir (#0A0A0A), pour fonds clairs
- `logo-red.svg` — rouge de marque (#CC0000), monochrome

## PNG (transparent)
- `logo-color-{16,32,48,64,128,256,512,1024}.png`
- `logo-white-{128,256,512}.png`
- `logo-black-{128,256,512}.png`
- `logo-red-{128,256,512}.png`

## Icônes d'application
- `icon-192.png`, `icon-512.png` — icônes PWA
- (favicon : `/app/icon.svg` — câblé automatiquement par Next.js)
- (icône Apple : `/app/apple-icon.png` 180×180 sur fond sombre)

## Réseaux sociaux
- `/public/og-image.png` — 1200×630, logo blanc centré sur fond sombre (partage Open Graph)

## Quand utiliser quoi
- **Fond sombre** → `logo-white.svg` ou `logo-color.svg`
- **Fond clair** → `logo-black.svg` ou `logo-color.svg`
- **Aplat / tampon / 1 couleur** → `logo-red.svg` ou `logo-black.svg`
- **Impression / grand format** → toujours le **SVG**
